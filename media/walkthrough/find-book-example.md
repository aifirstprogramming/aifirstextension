## Insert Book Code with Find Book Example

The quickest way to get a book example into your file. It works without Copilot, a GitHub sign-in or a network connection, and never uses AI credits.

### Steps

1. Open the file you want the code in (a new untitled file is fine) and place your cursor, or select code to replace.
2. Run **AI First: Find Book Example…** with the button, the editor's right-click menu, or `Ctrl+Alt+Shift+B` (`Cmd+Alt+Shift+B` on Mac).
3. Paste the prompt from the book and press `Enter`.
4. The matching code opens beside your file. Choose **Insert**, **Copy**, or **Open in New Editor**.

Matching follows your file's language: a `.py` file gets the Python book's code, a `.java` file the Java book's. `Ctrl+Z` / `Cmd+Z` undoes an insert.
