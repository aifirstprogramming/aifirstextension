## Copy an Example Prompt

1. In the example view, click **Copy Prompt**. The button shows **"✓ Copied!"** when the prompt is on your clipboard.
2. Paste it into **AI First: Find Book Example…** to insert the book's code, or into VS Code's chat with the AI First model selected.

You're copying the **prompt** (the instruction from the book), not the code. To take the code directly, use **Copy Response**, or **Insert into Editor** to put it into the last file you edited.
